Ejercicio 9 · Método aprender

Antes de empezar

Dentro de un método, this señala al objeto que lo invoca.

const gato = { juguetes: [], aprender: function (juguete) { this.juguetes.push(juguete); } };
gato.aprender("pelota");
console.log(gato.juguetes); // ["pelota"]

Tu turno
