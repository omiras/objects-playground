Ejercicio 8 · Color puro

Antes de empezar

Un color puro tiene un canal a 255 y los otros dos a 0.

const color = { r: 255, g: 0, b: 0 };
console.log(color.r === 255 && color.g === 0 && color.b === 0); // true

Tu turno

Abre la consola del navegador (F12 → Consola).

Completa solo el cuerpo de detectPureColor para examinar los tres componentes RGB del objeto. Devuelve "red", "green" o "blue" solo cuando ese componente vale 255 y los otros dos valen 0. En cualquier otro caso, devuelve una cadena vacía. No modifiques la declaración de la función ni las llamadas de prueba.

Edita el último <script>, guarda el archivo y recarga la página.

Resultado esperado en la consola

green
blue
