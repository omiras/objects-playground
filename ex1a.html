Ejercicio 1a · Crear un objeto

Antes de empezar

Un objeto se escribe entre llaves; un array, entre corchetes.

const ejemplo = { nombre: "Ana", hobbies: ["leer", "nadar"] };
console.log(ejemplo.hobbies);

Tu turno

Abre la consola del navegador (F12 → Consola).

Crea un objeto personal con nombre, apellidos, edad y hobbies. Muéstralo.

Edita el último <script>, guarda el archivo y recarga la página.

Resultado esperado

Por ejemplo, si usas estos datos:

{ nombre: "Ana", apellidos: "García", edad: 25, hobbies: ["leer", "nadar"] }
