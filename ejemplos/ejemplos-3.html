Ejemplo 3 · La palabra this

Antes de empezar

Dentro de un método, this se refiere al objeto que lo invoca.

const gato = { edad: 1, cumplir: function () { this.edad++; } };
gato.cumplir();
console.log(gato.edad); // 2
