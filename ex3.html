Ejercicio 3 · Añadir a un array del objeto

Antes de empezar

Puedes usar push en una propiedad que contiene un array.

const gato = { juguetes: ["pelota"] };
gato.juguetes.push("ratón");
console.log(gato.juguetes); // ["pelota", "ratón"]
